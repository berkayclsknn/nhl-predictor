# NHL Predictor

A Python project for exploring NHL data and building prediction models.

## Development

Create and activate a virtual environment, then install the project with its
development dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

Run the tests with:

```bash
pytest
```

## notes 
Whenever you open a new terminal to work on NHL Predictor, activate the virtual environment first:

cd ~/Desktop/nhl-predictor
source .venv/bin/activate
